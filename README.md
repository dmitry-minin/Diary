# Diary - Веб-приложение для ведения личного дневника

Diary - это современное веб-приложение, которое помогает организовать ваши мысли и 
воспоминания в удобном и стильном формате. 
Приложение построено на Django и использует Bootstrap для создания привлекательного интерфейса.
Для хранения данных используются базы данных SQLite.

## Основные возможности

- Создание и управление личными дневниками
- Ведение заметок с поддержкой изображений
- Поиск по дневникам и заметкам
- Удобная навигация с боковой панелью
- Темная тема для комфортного чтения

## Особенности

- Каждый пользователь имеет свой личный кабинет с доступом к своим дневникам и заметкам
- Возможность создавать заметки без авторизации (с последующим редактированием после входа)
- Простой и интуитивный интерфейс с акцентом на удобство использования
- Быстрый поиск по содержимому дневников и заметок

## Установка и использование

1. Установите Python и Django.
2. Скачайте и распакуйте архив с кодом проекта.
3. Переходите в директорию проекта и выполните команду `python3 manage.py runserver` для запуска сервера.
4. Откройте браузер и перейдите по адресу `http://localhost:8000` для открытия приложения.
5. Выполните команду `python3 manage.py createsuperuser` для создания суперпользователя (по необходимости).
6. Заходите в административную панель (по умолчанию `http://localhost:8000/admin/`) и создайте новый дневник и заметку.
7. Запуск с помощью Docker:
    - Соберите Docker-образ: `docker-compose build
    - Ппримените миграции: `docker-compose exec web python manage.py migrate`
    - Создайте суперпользователя: `docker-compose exec web python manage.py createsuperuser`
    - Запустите Docker-контейнеры: `docker-compose up`
    - Переходите по адресу `http://localhost:8000`
    - Для остановки: `docker-compose down`
    - Для полной очистки: `docker-compose down -v`
